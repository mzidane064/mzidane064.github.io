# Muhammad Zidane — Personal Portfolio

Personal academic portfolio website for Muhammad Zidane.

## Files

- `index.html` — main page
- `style.css` — styling and responsive layout
- `script.js` — navigation, dark mode, scroll animation
- `assets/` — place images, CV, documents, icons, etc. here

## Deploy with GitHub Pages

1. Create a repository named `USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. Your website will be available at `https://USERNAME.github.io/`.

## Before publishing

Replace:
- `https://github.com/` with your actual GitHub profile URL.
- `your.email@example.com` with your real email.
- Add your photo/CV/social links if desired.
- Add project links as each project becomes available.
